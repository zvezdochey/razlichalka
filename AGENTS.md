# Инструкции для ИИ-агентов (Claude Code и Codex)

Этот файл читают и Claude (через CLAUDE.md), и Codex. Пиши правила сюда, а не в два места.

## Проект

«Различалка» — сравнивает решения двух версий системы принятия решений (СПР):
какие заявки поменяли решение, кого это затронуло и почему.
Хакатон Nuclear IT Hack, задача от Баланс-Платформы. Подробнее — в README.md.

## Стек и папки

- `backend/` — Python + FastAPI
- `frontend/` — React + TypeScript (Vite)
- Запуск — Docker Compose

## Главные правила

- **API — это договор.** Формат всех ручек описан в `docs/api.md`. Не меняй формат ответа молча:
  если нужно поменять — сначала поправь `docs/api.md` и скажи об этом человеку.
- **Работай только в своей папке.** Бэкенд-задача → только `backend/`. Фронтенд-задача → только `frontend/`.
- **Коммиты** — в формате `тип: что сделал` (feat, fix, style, docs, chore). Подробно — в CONTRIBUTING.md.
- **Никогда не коммить** `node_modules/`, `venv/`, `.env`, ключи, токены и настоящие данные организаторов.
- **Не пушь в `main`.** Только своя ветка и Pull Request.

## Как работать

- Пиши просто и понятно: код читают люди, которые будут объяснять его жюри.
- Перед тем как сказать «готово» — запусти и проверь, что работает.
- Для фронта проверяй результат в браузере (Playwright), а не только «код скомпилировался».
- Если не уверен, как работает библиотека, — смотри свежую документацию через Context7, а не по памяти.
- Объяснения и комментарии в коде — на русском.
