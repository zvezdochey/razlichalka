## Правила, чтобы четверым не мешать друг другу

1. **Фронт делят трое.** Каждая новая вкладка — свой файл `frontend/src/pages/run/<Имя>Tab.tsx` (+ свой `.css`).
   Общие файлы (`App.tsx`, `pages/RunPage.tsx`, `api/types.ts`, `api/endpoints.ts`, `api/index.ts`) правим
   **только дописыванием в конец**, маленькими PR, и `git pull` перед правкой.
2. **Бэкендер на фронте соблюдает `frontend/CLAUDE.md` и `frontend/PLAN.md`** — визуальный язык там уже зафиксирован.
   Фронтовый PR от бэкендера первым смотрит Саня, сливает Семён.
3. **Бэковые PR смотрит Егор или Илья, сливает Семён.** Если Семён в задаче больше часа, PR с одобрением двоих
   сливает Егор — Семён не должен быть узким местом.
4. **Моков для `checks`, `facts`, `procedures` на фронте нет** — новые вкладки пишем сразу против настоящего бэка
   (`VITE_USE_MOCKS=false`). Автор вкладки — автор ручки, расхождений не будет.
5. **Меняешь формат ответа — сначала `docs/api.md`, потом код, и пишешь Сане.** Как и раньше.
6. **Бэк:** перед PR `code-reviewer-back` (+ `api-tester` для ручек). **Фронт:** `browser-tester` → `ui-designer` →
   `code-reviewer-front`.
