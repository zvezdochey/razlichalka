## Правила, чтобы четверым не мешать друг другу

1. **Фронт делят трое.** Каждая новая вкладка — свой файл `frontend/src/pages/run/<Имя>Tab.tsx` (+ свой `.css`).
   Общие файлы (`App.tsx`, `pages/RunPage.tsx`, `api/types.ts`, `api/endpoints.ts`, `api/index.ts`)
   правим **только дописыванием в конец**, маленькими PR, и сразу `git pull` перед правкой.
2. **Фронтовый PR от бэкендера смотрит Саня** (знает свой код), потом сливает Семён.
3. **Бэковые PR смотрит Егор или Илья, сливает Семён.** Семён не должен быть узким местом: если он в
   задаче больше часа, PR с одобрением двоих сливает Егор.
4. **Моков для `checks`, `facts`, `procedures` на фронте нет** — новые вкладки пишем сразу против настоящего
   бэка (`VITE_USE_MOCKS=false`, `uvicorn` локально). Это нормально: автор вкладки — автор ручки.
5. **Меняешь формат ответа — сначала `docs/api.md`, потом код, и пишешь Сане.** Как и раньше.
6. Задачи с исключением «работаю не в своей папке» помечены явно. В рамках одной задачи — одна папка.
