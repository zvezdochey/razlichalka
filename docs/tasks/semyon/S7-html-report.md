# S7. HTML-отчёт

**Кто:** Семён · **Ветка:** `semyon/report` · **Папка:** `backend/app/` · **Зависит от:** S6 (читалка результатов)

**Запуск в новом чате:** «Выполни задачу из `docs/tasks/semyon/S7-html-report.md`. Сначала прочитай `AGENTS.md`, `docs/api.md` (п. 11) и `docs/tasks/CONTRACTS.md`.»

## Зачем
По ТЗ результат должен быть и в браузере, и скачиваемым HTML, который читается без приложения (`docs/api.md` п. 11; `frontend/DESIGN.md` п. 10).

## Что сделать
1. Шаблон `backend/app/templates/report.html` (Jinja2, **весь CSS внутри файла**, без внешних ресурсов и скриптов — документ должен открываться офлайн). Палитра — из `frontend/DESIGN.md` (фон `#F5F5F3`, акцент `#C93620`, текст `#181818`). Содержимое:
   - заголовок: название конфигурации, `id` запуска, дата, датасет (BEFORE=MASTER, AFTER=BETA);
   - 4 показателя: заявок в прогоне, с различиями (число и доля), сменили решение, всего изменённых атрибутов;
   - блок «Переходы решений»: таблица `approve→reject`, `reject→approve`, без изменений, `other`;
   - «Атрибуты»: сколько `VALUE_CHANGED / ATTRIBUTE_NEW / ATTRIBUTE_LOST`;
   - «Топ-20 заявок по числу изменённых атрибутов»: `app_id`, решение до → после, `attributes_changed`;
   - блок «Проверки»: пока «Проверки не подключены» (после S10 заполнится таблицей);
   - внизу ссылка «Открыть в приложении»: `{origin}/runs/{id}`.
2. Ручки:
   - `GET /api/runs/{id}/report` — HTML (`text/html; charset=utf-8`);
   - `GET /api/runs/{id}/report.html` — то же с `Content-Disposition: attachment; filename="report-<id>.html"`;
   - запуск не `ready` → `not_ready` 409 (ошибка в JSON-формате); чужой/неизвестный → 404.
3. `origin` — из заголовков запроса (`X-Forwarded-Proto` + `X-Forwarded-Host`/`Host`), чтобы за nginx ссылка была `http://localhost:3000/runs/<id>`, а не внутренний адрес. Не подставлять в HTML ничего без экранирования (Jinja autoescape включён) — названия конфигураций пишет пользователь.
4. Все числа читать из `summary.json` и `apps.csv` — не пересчитывать.

## Тесты
Отчёт на `run_mini`: содержит число заявок и ссылку `/runs/<id>`; XSS-проверка — название конфигурации `<script>alert(1)</script>` попадает в HTML экранированным; `report.html` отдаёт заголовок скачивания; неготовый запуск → 409.

## Готово, когда
Скачанный файл открывается двойным кликом без интернета и читается; открывается в браузере по ссылке из фронта.

## Не делай
Интерактив и графики на JS — не нужно, и ИИ-мнение (п. 12) — после MVP.
