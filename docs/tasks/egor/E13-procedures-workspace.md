## Зачем
Три шага демо зависят от этого экрана:
- шаг 1 — «для процедуры покажите выбор источника: интерактивная рабочая область или файл `.py`»;
- шаг 2 — «провалитесь из журнала в код этапа»;
- шаг 7 — «напишите новую проверку прямо в приложении, примените её и покажите, что она попала в тот же отчёт».

На защите организаторы могут подложить свою проверку — экран должен это пережить.

## Что сделать
1. **API:** в конец `types.ts` / `endpoints.ts` — `Procedure`, `ProcedureInput`, `ValidateResponse`; `listProcedures(kind)`,
   `getProcedure(id)` (с `code`), `createProcedure`, `updateProcedure`, `deleteProcedure`, `validateProcedure`.
2. **Страница «Процедуры»** (`pages/ProceduresPage.tsx`, пункт в боковом меню, маршрут `/procedures`):
   - слева список процедур по видам (`check`, `normalize`, `aggregate`), у встроенных — пометка «встроенная», их
     можно открыть только на чтение;
   - справа редактор: название, источник **«Рабочая область» / «Файл на сервере»** (переключатель; для файла —
     поле пути), `<textarea>` с моноширинным шрифтом, номерами строк сбоку и `Tab` = 4 пробела;
   - **«Проверить»** → `/procedures/validate`, ошибки списком «строка N: текст», строка в редакторе подсвечена;
   - **«Сохранить»** → `POST`/`PUT`; `bad_code` с бэка — так же, как ошибки проверки;
   - «Новая проверка» вставляет шаблон по контракту (`CHECK = {...}`, `def run(mart, params) -> list[dict]`) с
     комментариями на русском;
   - сворачиваемая справка: контракт `CHECK`, поля строки результата, методы `mart.*` — кратко, из `checks/README.md`.
3. **Подключить к прогону** — кнопка «Добавить в конфигурацию и запустить»: выбрать конфигурацию → `PUT /configs/{id}`
   с новой проверкой в `checks` → `POST /runs` → переход на страницу нового прогона. Это и есть шаг 7 демо одной кнопкой.
4. **Код этапа из журнала** (шаг 2): в журнале этапов (F4 Сани) у этапа есть `code_ref`. Клик по нему открывает
   процедуру `code_ref.procedure_id` на этой странице (только чтение для встроенных) с прокруткой к `code_ref.line`.
   В журнале это одна ссылка — согласуй с Саней, кто её добавляет.
