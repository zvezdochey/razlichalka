## Зачем
Шаг 6 демо: «Откройте отчёт проверок: все проверки одной таблицей с вердиктами, переход из строки к заявкам».
Пример такой таблицы — в ТЗ (раздел с FAIL/PASS и бледной последней строкой).

## Что сделать
1. **API:** в конец `src/api/types.ts` — `CheckRow` (`check_id`, `check_name`, `source`, `argument`, `numbers`, `metric`,
   `result: 'PASS' | 'FAIL'`, `apps_ref`, `faint`), `ChecksResponse`; в конец `endpoints.ts` — `getChecks(runId, { result, page, size })`
   и `getFactApps` (если Илья ещё не добавил в I2 — добавь ты, договоритесь, кто первый).
2. **Маршрут:** `pages/run/ChecksTab.tsx` (+ `.css`), в `App.tsx` вложенный маршрут `checks`, в `RunPage.tsx` —
   `NavLink` «Проверки». Только эти строки в общих файлах.
3. **Таблица:** Проверка · Срез · Аргумент · Кол-во / база · Метрика · Результат · Уверенность · Заявки.
   - `PASS` — зелёный; `FAIL` + не `faint` — выраженный красный; `FAIL` + `faint` — **бледная подложка и подпись
     «Низкая уверенность»**, результат остаётся FAIL. Цвета — токены из `styles/tokens.css`, не выдумывать.
     Это единственное место в продукте, где цвет означает оценку.
   - Сверху переключатель «Все / только FAIL» (`result=FAIL`) и счётчик «FAIL: N из M».
   - Сортировка по умолчанию: FAIL уверенные → FAIL бледные → PASS.
   - «Заявки» — число-ссылка; `apps_ref = null` → «—».
4. **Провал к заявкам:** клик по числу → справа список заявок (`/facts/{ref}/apps`) → клик по заявке → `/runs/:id/apps?app=<app_id>`
   (так открывается панель заявки из F7 Сани).
5. **Ошибка пользовательской проверки** (по S10 она не валит запуск, а пишет строку `error` в журнал этапа `checks`) —
   над таблицей плашка «Проверка X не выполнилась — см. журнал» со ссылкой на вкладку «Журнал». Ошибка ≠ FAIL.
6. **«Обзор»:** карточка «Проверки с FAIL» (`checks_fail` из `summary`) становится ссылкой на эту вкладку.
   Сама карточка — код Сани (F5), согласуй с ним, кто правит.
7. Состояния: идёт расчёт — «Проверки ещё считаются» (этап `checks` не `ready`); проверок в конфигурации нет —
   `EmptyState` «В конфигурации не выбраны проверки».
