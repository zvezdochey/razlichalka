## Зачем
ТЗ: после прогона система получает у языковой модели «независимый взгляд на результат — что выглядит подозрительно
и на что посмотреть аналитику». «Витрину целиком в модель не отправить, поэтому придётся решить, что именно ей
показать… Это решение — часть задачи». То есть оценивают **выбор входа**, а не красоту текста.

## Что сделать
1. **Что отправляем** (`app/services/ai_review.py`, собрать в один текст до ~8 тыс. токенов):
   - `summary.json` целиком;
   - топ-10 причин из `/reasons` (I3) и `change_sources` (E10);
   - все строки FAIL из `checks.csv`;
   - топ-30 путей по числу изменённых строк (`PATH × CHANGE_TYPE` из фактов);
   - 20 примеров изменённых атрибутов у заявок со сменой решения (путь, до, после).
   Этот список — то, что ты расскажешь жюри. Запиши его в docstring модуля.
2. **Когда считаем:** фоном после того, как запуск стал `ready` (не блокировать сам запуск). Результат —
   `ai_review.json` в папке запуска; повторно не считаем.
3. **`GET /api/runs/{id}/ai-review`** (п. 12): `pending` → `ready` с `text` и `generated_at` / `error` с понятным
   текстом. Запуск не `ready` → 409.
4. **Ключ** — только из переменной окружения (`AI_API_KEY` или имя по SDK). `.env.example` — с пустым значением,
   `docker-compose.yml` — передать переменную. **Ключ в Git не коммитим.** Нет ключа → `status: "error"`,
   «Мнение ИИ не настроено: нет ключа», остальной отчёт работает.
5. **Промпт** — на русском: роль «второе мнение для риск-аналитика», просьба опираться только на переданные числа,
   разделить «вероятно поломка» / «вероятно ожидаемый эффект правки» / «вероятно входные данные». 5–8 пунктов.
6. **Фронт** — маленький блок на «Обзоре» (состояния «Считаем…» / текст / ошибка, опрос раз в 3 с). Это код Сани
   (F5): или блок добавляет Саня, или ты отдельным PR в `frontend/`, если Саня согласен.

## Тесты
Без настоящего вызова модели: подмена клиента; проверка, что вход не больше лимита и содержит FAIL-строки;
без ключа → `error`, запуск остаётся `ready`.

## Готово, когда
На настоящем прогоне с ключом текст появляется на «Обзоре»; без ключа — понятная ошибка, ничего не падает.
