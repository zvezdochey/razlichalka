## Что сделать
Файл `backend/pipeline/flatten.py` (+ `backend/pipeline/errors.py` с `PipelineError`, `BadFile`, `Cancelled` из CONTRACTS §4).

```python
def flatten_response(doc: dict, app_id: str, source: str, array_rules: dict,
                     ignore_paths: list[str] = (), adjust=None) -> list[dict]:
    """Возвращает строки с ключами: APP_ID, SOURCE, PREFIX, CLASS, SUFFIX, ARRAY_KEY, KEY, PATH, VALUE, ADJUSTED_VALUE."""
```

`array_rules` — словарь `{путь_массива_с_[]: {"mode": "key"|"value"|"index", "key": ["product_id", "type"]}}`.
Формат правил задаёшь ты, но в E2 он станет `DEFAULT_ARRAY_RULES`. `adjust(path, value_str) -> str` — функция бакетизации
из E4; если `None` — `ADJUSTED_VALUE = VALUE`.

Правила обхода:
1. Идём по dict рекурсивно. Лист (строка, число, bool, null) → строка результата. Формат `VALUE` — CONTRACTS §2.1.
2. Массив: по правилу для его `PATH`.
   - `key` — для каждого элемента ключ собирается из полей `key` (поддержи вложенные через точку: `body.action`), составной ключ склеивается через `:` внутри одного массива (`15210:standard`). В `PATH` вместо индекса `[]`, в `ARRAY_KEY` — ключ.
   - `value` — массив скаляров: ключ = само значение элемента; сам элемент — лист.
   - `index` — ключ = порядковый номер с нуля.
   - Вложенные массивы: `ARRAY_KEY` склеивает ключи через `|`.
3. Пути из `ignore_paths` пропускаются (сравнение по `PATH` и по префиксу).
4. Пустой массив/объект → один лист со значением `[]` / `{}`.
5. Массив, для которого **нет правила** → `BadFile`-подобная `PipelineError(code="bad_file", ...)` с понятным текстом «нет правила для массива <путь>». Молча подставлять индекс нельзя.
6. Два элемента с одинаковым ключом в одном массиве → ошибка с путём и ключом (дубль ключа = неверный ключ).

## Тесты (`backend/tests/pipeline/test_flatten.py`)
Маленькие выдуманные JSON внутри теста (не данные организаторов):
- простой вложенный dict;
- массив по ключу — порядок элементов в разных документах разный, а строки одинаковые;
- составной ключ (`product_id` + `type`) — две строки с одним `product_id` не склеились;
- `index`-массив: `[0.452, 0.593, 0.637]` → `ARRAY_KEY` `...|0`, `...|1`, `...|2`;
- вложенный массив → `ARRAY_KEY` с `|`;
- `ignore_paths`; `null`, `true`, пустой массив; дубль ключа → ошибка.
