## Как не сломать друг друга

- Исправления делает владелец папки из задачи. Чужие файлы не трогаем.
- Тестовые прогоны через API создаём с заголовком `X-User: demo`, иначе прогон виден только «anonymous» и в UI выглядит как «Запуск не найден».
- Эталон организаторов (`ПАКЕТ/ОРГАНИЗАТОРАМ/`) в Git не коммитим.
