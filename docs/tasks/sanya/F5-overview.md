# F5. Вкладка «Обзор»: счётчики и переходы решений

**Кто:** Саня · **Ветка:** `front/overview` · **Папка:** `frontend/` · **Зависит от:** F4

**Запуск в новом чате:** «Выполни задачу из `docs/tasks/sanya/F5-overview.md`. Сначала прочитай `AGENTS.md`, `docs/api.md` (п. 7.1) и `frontend/DESIGN.md` (п. 6).»

## Зачем
Ответ «за минуту»: сколько заявок затронуто и у скольких сменилось решение.

## Что сделать (вкладка `/runs/:id`, «Обзор», данные — `GET /summary`)
1. **Четыре показателя** сверху (крупные цифры 30–36 px, цифры табличные):
   - «Заявок в прогоне» — `applications`, подпись «уникальные заявки»;
   - «С различиями» — `applications_changed` + `applications_changed_share` в процентах, подпись «доля от прогона»;
   - «Сменили решение» — `decision_changed` (кликабельно → вкладка «Заявки» с фильтром «любая смена»);
   - «Проверки с FAIL» — пока «—» с подсказкой «проверки подключатся позже» (в MVP нет данных).
2. **Переходы решений:** компактная таблица/матрица `approve → reject`, `reject → approve`, «решение то же», «другое» с числами и долями; ячейка кликабельна → вкладка «Заявки» с фильтром `decision_change` в URL (`?decision_change=approve_to_reject`). Отдельно заметна строка «Различия есть, решение то же» (= `applications_changed − decision_changed`, если число положительное — подпиши как «приблизительно», считать лучше аккуратно и подписать формулу в `title`).
3. **Атрибуты:** горизонтальные полосы по `attributes` (`VALUE_CHANGED`, `ATTRIBUTE_NEW`, `ATTRIBUTE_LOST`) с названием по-русски («Значение изменилось», «Атрибут появился», «Атрибут исчез») и числом. Подпись: «Строки атрибутов, не уникальные заявки» — одна заявка входит во многие.
4. Состояния: загрузка, ошибка (`ErrorBox`), пустой результат (`applications_changed = 0` → «Различий нет» не прячет остальные показатели).
5. Числа форматируются с пробелами как разделитель тысяч (`385`, `1 617`).
6. Переиспользуй цвета токенов; красный не для «плохо/хорошо» — он только для акцента (см. `DESIGN.md`).

## Готово, когда
Обзор на моках показывает числа из `docs/api.md` п. 7.1; клики ведут в «Заявки» с правильным фильтром; проверено `browser-tester` и `ui-designer` (читаемость на 1366×768).
