# F7. Панель заявки: атрибуты до и после

**Кто:** Саня · **Ветка:** `front/app-panel` · **Папка:** `frontend/` · **Зависит от:** F6

**Запуск в новом чате:** «Выполни задачу из `docs/tasks/sanya/F7-app-panel.md`. Сначала прочитай `AGENTS.md`, `docs/api.md` (п. 8.1) и `frontend/DESIGN.md` (п. 8, 11).»

## Зачем
Финал пути «итог → заявки → заявка → атрибут»: пользователь видит, что именно поменялось.

## Что сделать (панель по `?app=<id>` из F6, данные — `GET /apps/{app_id}/attributes`)
1. Широкая боковая панель справа поверх таблицы (на узком экране — на весь экран). Закрывается кнопкой «×» и клавишей Escape, фокус возвращается на исходную строку. Прямая ссылка `?app=…` открывает панель сразу.
2. Шапка: `APP_ID`, `Решение: approve → reject` (из списка заявок; если в списке строки нет — запрос `GET /apps?search=<id>`), число изменённых атрибутов.
3. Панель управления: поиск по пути (`search`), переключатель «Только различия» (`only_diff=1`; по умолчанию включён), фильтр по типу изменения.
4. Таблица «Атрибут / Элемент массива / BEFORE / AFTER / Тип»:
   - `path` — monospace, длинный путь переносится по точкам; `array_key` — отдельной колонкой/чипом (одинаковый `path` ещё не значит один элемент);
   - `value_before` / `value_after`: если `null` — серый курсив «Отсутствует» (это не пустая строка, не `0`, не строка `null`);
   - рядом с числом — бакет мелким серым текстом (`adjusted_*`); если значение поменялось, а бакет нет — добавить подпись «в пределах того же диапазона», чтобы изменение не терялось;
   - тип изменения — бейдж: `VALUE_CHANGED` «Значение изменилось», `ATTRIBUTE_NEW` «Появился», `ATTRIBUTE_LOST` «Исчез», `SAME` «Без изменений»; цвет не единственный признак (есть текст);
   - строки с различиями слегка подсвечены.
5. Пагинация `size=100`; «Загрузить ещё» или страницы. Состояния: загрузка, ошибка, «Различий нет».
6. Доступность: `role="dialog"`, `aria-label`, ловушка фокуса внутри панели.

## Готово, когда
На моках и настоящем бэке: клик по заявке открывает панель с атрибутами; `null` показан как «Отсутствует»; Escape закрывает; ссылка `?app=` открывается после перезагрузки. Проверено `browser-tester` и `ui-designer`.
