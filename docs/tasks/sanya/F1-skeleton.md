# F1. Скелет фронта: Vite, React, TypeScript, каркас экрана

**Кто:** Саня · **Ветка:** `front/skeleton` · **Папка:** `frontend/` · **Зависит от:** ничего. **Делай первой.**

**Запуск в новом чате:** «Выполни задачу из `docs/tasks/sanya/F1-skeleton.md`. Сначала прочитай `AGENTS.md`, `docs/api.md` и `frontend/DESIGN.md`.»

## Зачем
Общий каркас: сборка, маршруты, шапка и меню, цвета. На нём строятся остальные экраны.

## Что прочитать
`frontend/DESIGN.md` (разделы 2, 3, 11), `frontend/mockup.html` (открыть в браузере — как должно выглядеть).

## Что сделать
1. `frontend/`: Vite + React + TypeScript (`npm create vite@latest`, шаблон `react-ts`), зависимости: `react-router-dom`. Больше библиотек не добавляй без нужды (свежие версии смотри в Context7).
2. `vite.config.ts`: dev-прокси `/api` → `http://localhost:8000` (чтобы во фронте всегда писать относительные адреса `/api/...`).
3. Цвета и отступы — **CSS-переменными** в `src/styles/tokens.css` из `DESIGN.md` п. 2 (`--bg`, `--surface`, `--text`, `--muted`, `--border`, `--accent`, `--accent-2`, `--ok`, `--info`, радиусы 6–8 px, шаги 4 px). Один общий `src/styles/base.css`: шрифт, таблицы, кнопки (основная красная и обычная), бейджи статусов.
4. Каркас `src/layout/AppLayout.tsx`: тёмная шапка 56 px (название «Различалка», справа имя пользователя) + левое меню ~200 px: «Прогоны», «Конфигурации» (второе пока неактивная заглушка «скоро»), область контента справа. Ориентир экрана — ноутбук 1366×768.
5. Маршруты (`react-router`), пока с пустыми страницами-заглушками:
   - `/` → редирект на `/runs`
   - `/runs` — список прогонов
   - `/runs/new` — новый прогон
   - `/runs/:id` — прогон (внутри вкладки: `overview` по умолчанию, `apps`, `log`)
6. Имя пользователя: берём из `localStorage` (`razlichalka_user`), по умолчанию `demo`. Его потом отправляет клиент API в заголовке `X-User` (F2).
7. Общие компоненты: `Spinner`, `ErrorBox` (показывает `message` ошибки как есть), `EmptyState`.
8. `README` в `frontend/`: как запустить (`npm install`, `npm run dev`, `npm run build`), структура папок в 5 строк.
9. В `.gitignore` уже есть `node_modules/`, `dist/` — проверь, что в коммит они не попали.

## Готово, когда
`npm run dev` открывает страницу с шапкой, меню и тремя маршрутами; `npm run build` без ошибок; фокус на кнопках и пунктах меню виден; в консоли браузера пусто (проверь Playwright или `browser-tester`).

## Не делай
Запросы к API (F2), экраны (F3–F7).
