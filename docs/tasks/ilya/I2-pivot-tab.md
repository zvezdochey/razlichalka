> соблюдай `frontend/CLAUDE.md` и `frontend/PLAN.md` (визуальный язык там зафиксирован), PR первым смотрит Саня.

**Запуск в новом чате:** «Выполни задачу из `docs/tasks/ilya/I2-pivot-tab.md`. Сначала прочитай `AGENTS.md`, `frontend/CLAUDE.md`, `frontend/PLAN.md`, `docs/api.md` (п. 7.2, 7.3), `frontend/DESIGN.md` (п. 7) и пункт 2 в `docs/tasks/sanya/F9-after-mvp.md`. Запросы — только через `src/api`.»

## Зачем
Шаг 4 демо. Жюри будет менять раскладку и смотреть, насколько быстро отвечает. ТЗ разрешает готовые
pivot-компоненты, но мы **считаем на сервере** (`/facts`), а фронт рисует уже агрегат: готовая библиотека
считала бы в браузере по 290 тыс. сырых строк. Это решение надо уметь объяснить на защите — запиши его
одной фразой в описание PR.

## Что сделать

### 1. Слой API
- В конец `src/api/types.ts`: `FactsParams` (`dims: string[]`, `filter?: Record<string, string[]>`, `measure`, `limit?`),
  `FactsRow` (значения измерений + `counts` + `app_ids_ref`), `FactsResponse` (`dims`, `rows`, `total_groups`),
  `FactAppsResponse`.
- В конец `src/api/endpoints.ts`: `getFacts(runId, params, { signal })`, `getFactApps(runId, ref, page, size)`.
  Склейка `filter` в строку `поле:з1,з2;поле:з` — внутри функции, экран про формат не знает.
- Моки не нужны: работай против настоящего бэка (`VITE_USE_MOCKS=false`, бэк через `uvicorn` или `docker compose`).

### 2. Маршрут и вкладка
- `pages/run/PivotTab.tsx` (+ `PivotTab.css`). В `App.tsx` — вложенный маршрут `pivot`, в `RunPage.tsx` —
  `NavLink` «Сводная» между «Обзор» и «Заявки». Это две строки в чужих файлах — больше там ничего не трогай.

### 3. Редактор раскладки
- Три зоны: **Строки** (1–2 поля), **Колонки** (0–1 поле), **Фильтры**. Поле выбирается из списка измерений
  с человеческими подписями: `PATH` — «Атрибут», `CHANGE_TYPE` — «Тип изменения», `ARRAY_KEY_1` — «Продукт
  (ключ массива)», `DECISION_CHANGED` — «Решение изменилось», `DECISION_BEFORE/AFTER`, `PD_MODEL_*`, `PARTNER_TYPE`,
  `ROUTING_METHOD`, после E10 — `CHANGE_SOURCE` «Источник изменения». Перетаскивание не обязательно — достаточно
  выпадающих списков и кнопки «поменять строки и колонки местами».
- Показатель: переключатель «Строк витрины» (`counts`) / «Заявок» (`counts_distinct_apps`).
- Фильтр по умолчанию `DIFF_FLAG:1` (иначе 90% строк — `SAME`); снять можно.
- **Готовые представления** кнопками сверху:
  - «По атрибутам» — строки `PATH`, колонки `CHANGE_TYPE` (это и есть шаг 4 демо);
  - «По продуктам» — строки `ARRAY_KEY_1`, колонки `CHANGE_TYPE`;
  - «По решениям» — строки `DECISION_BEFORE`, колонки `DECISION_AFTER`, показатель «Заявок».
- Раскладка хранится в адресе (`?rows=PATH&cols=CHANGE_TYPE&f=DIFF_FLAG:1&m=counts`) — ссылкой можно поделиться,
  и HTML-отчёт (S7) может вести прямо в нужную раскладку.

### 4. Таблица
- Из `rows` ответа собрать матрицу строки × колонки на клиенте (это уже маленький агрегат).
- Шапка и первая колонка закреплены, прокрутка внутри панели. Длинные `PATH` — моноширинным шрифтом с переносом.
- Итоги по строкам и колонкам — **только для `counts`**. Для «Заявок» итог суммой нельзя (одна заявка попадает
  в несколько атрибутов) — показывай «—» и подсказку. **Не называй сумму `counts` по атрибутам числом заявок.**
- Если `total_groups > rows.length` — строка «Показаны первые N групп из M, сузьте фильтр».
- Цвет: значения не красим (см. `frontend/CLAUDE.md` — цвет только у результатов проверок). Можно бледную
  тепловую подложку в одном нейтральном тоне.

### 5. Провал до заявки
- Клик по ячейке → справа панель «Заявки группы» (`/facts/{ref}/apps`, пагинация по 50) с подписью группы.
- Клик по заявке → `/runs/:id/apps?app=<app_id>`: так открывается панель заявки из F7 Сани (параметр `?app=`).

### 6. Скорость и состояния
- Каждый новый запрос отменяет предыдущий (`AbortSignal`), смена раскладки не дёргает интерфейс.
- Состояния через готовые `Spinner`, `ErrorBox` (с «Повторить»), `EmptyState` («В этой раскладке нет различий»).
- В углу таблицы — время ответа `/facts` мелким серым («ответ за 0,12 с»). На защите это работает лучше слов.

## Готово, когда
`browser-tester` на настоящем прогоне: переключает три представления, меняет поле строк, ставит фильтр, кликает в
ячейку, открывает заявку — консоль без ошибок; скриншоты в PR. Затем `ui-designer` и `code-reviewer-front`.
PR смотрит Саня, сливает Семён.

## Не делай
Не тащи pivot-библиотеку и не грузи сырые строки витрины в браузер. Не трогай чужие вкладки и общие компоненты —
если нужен новый общий компонент, положи его рядом с `PivotTab.tsx`.
